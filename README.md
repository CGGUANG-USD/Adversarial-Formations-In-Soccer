Those are scripts for a so called Adersarial Formation In Soccer maya CG project.
There are two types of scripts included,mel commands and animation expressions.
The mel command script creates the GUI and the generative logic of two adversarial formations,
while the animation expressions keep the players moving naturally while playing the scene.
As you see,this project originates from the current hot soccer league in Hubei Province of China.
If you are also interested in such a project,any comments are appreciated and the assests should be uploaded on dropbox for sharing.
